# References

Published Herdr layouts to learn from when building monster-hunter. Each is
cloned into a folder here; the clones are git-ignored (see `.gitignore`).

- [herdr-traveler](https://github.com/franky5440-afk/herdr-traveler) → `herdr-traveler/`
- [herdr-kaiju](https://github.com/Jiqize/herdr-kaiju) → `herdr-kaiju/`

To fetch them again:

```sh
git clone --depth 1 https://github.com/franky5440-afk/herdr-traveler.git
git clone --depth 1 https://github.com/Jiqize/herdr-kaiju.git
```
