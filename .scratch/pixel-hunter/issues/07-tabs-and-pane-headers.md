# 07: Tabs and pane headers with Hunter faces

**What to build:** The tab bar and every pane header carry the Hunters.

- Each tab shows a 24 px face of its first Hunter (a map icon when the tab has no agent), its name and a state dot. The current tab is framed in mint.
- Files and Changes buttons on the right open Herdr's shipped panels in the side panel, remembered per space.
- Each pane header shows the Hunter's face, Class, Rank (or the program name until ticket 06 lands), folder, branch and state label.
- The focused pane is framed mint. A pane whose Hunter Needs help is framed peach, and peach wins over focus.

- **Not met, and why: peach over focus on the whole pane frame.** Herdr 0.1.13 draws pane frames itself from the tab block's `pane.border` / `pane.focus`. Those are one color for every pane, and there is no per-pane or per-status option (checked the layout docs, `herdr.d.ts`, `herdr-app commands` and the shipped layouts; a blocked fake agent got no special frame). A header mod can only paint its own 30 px strip. So a Needs-help pane gets a **peach header** (2 px `blocked` frame on a `blocked` 1f tint, `! NEEDS HELP` in peach) whether focused or not, but a focused Needs-help pane **keeps Herdr's mint outer frame** around it (`herdr-app shot`: mint outer frame, peach header inside). The model already decides "help wins" (`paneFrame`), so that box stays unticked until there's a way to draw it. Options:
  1. Ask Herdr for a status frame on the tab block (e.g. `pane.blocked: { width, color }`, used before `focus`). This is the clean fix and needs no mod change beyond dropping the header outline.
  2. Make the header own both signals: set `pane.focus` to `border` (no mint from Herdr) and have the header draw mint when focused and peach when Needs help. Peach then wins, but focus only frames the 30 px header, not the whole pane as in ticket 02 and the record.
  3. Toggle the layout's `pane.focus.color` with `layout.set` while the focused pane Needs help. Rejected: it rewrites the user's layout file (and the synced copy) on state changes, and still can't frame an unfocused Needs-help pane.
