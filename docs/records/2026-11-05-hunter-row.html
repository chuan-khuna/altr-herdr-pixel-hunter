Six layouts

Decisions

These were the open questions. All four are now decided, and layout F shows the result.

  1. Name. The Herdr tab name leads. The Class name follows it, dim.
  2. Context text. Used / window size (128k/200k), as Claude Code shows it. The bar stays Stamina (what's left), so it shrinks as the number grows, with the same blue → cream → peach colours.
  3. Program. Shown only when it isn't Claude Code (Monk · Codex).
  4. Pets. One line of animal icons under the Hunter, max 2 then [+N]. This replaces the indented Pet rows decided earlier (Q4). Needs help puts a peach frame on the icon. Hover shows type and task.
